How records are merged
  • Same email (case and spacing ignored), or the same Gmail inbox written differently (dots, +tags).
  • Same phone and the same name, ignoring accents. A name alone never merges two records.
  • If two different people share one address (for example info@), those rows go to the review list instead of being merged.
  • Every input row ends up in exactly one place: a contact, the merge log or the exceptions list.
