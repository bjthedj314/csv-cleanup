Contact lists and CRM exports

Same service, same price, for contact lists. You get one row per real person, and every merge comes with its reason.

  • Merged only on evidence: the same email; the same Gmail inbox written differently (dots, +tags); or the same phone and the same name. A name alone is never enough.
  • Shared inboxes are flagged, not merged: if two people share one address (for example info@), those rows go to a review list.
  • A merge log and a field-conflict report: which rows were combined, on what evidence, and which value was kept where duplicates disagreed.
  • One format: phones in +1 format, dates as YYYY-MM-DD, state codes, plain amounts. Spreadsheet-formula cells are made safe.
  • Every input row accounted for: kept, merged or flagged, never silently dropped.
